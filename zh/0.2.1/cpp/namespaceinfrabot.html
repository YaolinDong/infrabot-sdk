◆ Mode

enum class infrabot::Mode : uint8_t
strong

控制器的控制模式（INFRABOT_CONTROL_*）。

枚举值
Idle 

电机保持当前指令；不需要 PC 发流。

RtJoint 

PC 用 servej() 发送关节目标流。

RtCartesian 

PC 用 servep() 发送末端位姿流；控制器以 1 kHz 求解逆运动学。

NrtJoint 

用 movej() 做点到点关节运动。

NrtCartesian 

用 movep() 做末端直线运动。

GravityFree 

本地重力补偿：机械臂处于悬浮状态，可以用手拖动。

GravityLock 

本地重力补偿，并在当前位姿柔性保持。

JointImpedance 

以进入时的位姿为中心的本地关节阻抗。

CartesianImpedance 

以进入时的末端位姿为中心的本地笛卡尔阻抗。

JointAdmittance 

本地关节导纳；每个关节离限位至少要有 0.03 rad 余量。

CartesianAdmittance 

本地笛卡尔导纳；关节限位余量要求相同。

Unknown 

尚未知（收到第一包遥测之前）。

[Blocking] 报告正在运行的槽：A 或 B、已确认还是试运行，以及镜像 ID。

例如 "confirmed A 3f9c…"；板子停在引导程序中时为 "recovery-loader"。升级前后用它确认正在运行哪个镜像。

[Blocking] 让板子从另一个 A/B 槽启动。

新固件工作异常时使用：板子回到另一个槽中的固件。板子必须运行在正常应用中；在触摸屏上批准请求。另一个槽运行起来后调用返回。

参数

public_key_filePublisher public key; empty selects the SDK's release key.
portMaintenance port.
异常
std::runtime_errorOn refusal, timeout or verification failure.

◆ update_firmware()

bool infrabot::update_firmware ( const std::string &  ipv4,
const std::string &  package_path,
const std::string &  public_key_file = {},
std::function< void(unsigned, unsigned)>  progress = {},
uint16_t  port = 5002 
)

[Blocking] 在触摸屏上确认后安装签名 IFW 固件包。

板子在触摸屏上请求批准（60 s），把镜像写入未运行的槽并试运行。新应用确认自身后调用返回 true；试运行失败时板子回到之前的固件，调用抛出异常。完成的前提是重启后的应用回复了预期的镜像标签。

参数
ipv4Controller IPv4 address.
package_pathThe .ifw package.
public_key_filePublisher public key; empty selects the SDK's release key.
progressCalled with bytes sent and the total.
portMaintenance port.
返回
false without sending anything when the board already runs an image from this package.
异常
std::runtime_errorOn refusal, timeout, an invalid package or a verification failure.
