详细描述

InfraBot SDK 的 C++ 接口：每个机械臂控制器对应一个 Robot。

SDK 是控制器 UDP 协议（infrabot/protocol.h）的 PC 端。

Timing classes
Every function is tagged with how it behaves:
  • [Blocking] waits for the controller (a reply or telemetry), at most the time given. Never call it from a 1 kHz loop.
  • [Non-blocking] returns at once: it sends one datagram or copies state.
  • [RT] non-blocking and allocation-free on success: safe in a 1 kHz loop.

调用失败时返回 false（或结果码），并把原因写入 error。错误信息为中文。

Lifecycle
connect() → set_motor_profile() (drives disabled, IDLE; runs the controller's parameter self-check) → servo_on() → switch_mode() → commands → stop() or switch_mode(Mode::Idle) → servo_off().

连接期间，SDK 让控制器在 IDLE 和 NRT 模式下保持存活（100 Hz 心跳和 movej/movep 会话）。在 RT 模式下，必须持续调用 servej() 或 servep()（至少 10 Hz，通常 1 kHz），或者改用 start_joint_stream()，并在其生产者超时内刷新 servej()。

PC 静默（程序关闭、网线拔出）时，控制器会受控停止并让机械臂保持使能。它从不自行让电机失能（需要带 INFRABOT_CAP_CONTROLLED_STOP 的固件；更早的固件会失能）。
