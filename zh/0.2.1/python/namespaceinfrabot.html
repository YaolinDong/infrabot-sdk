详细描述

InfraBot SDK 的 Python 接口。

每个机械臂控制器对应一个 Robot。关节量使用国际单位：rad、rad/s、N·m。调用失败时抛出 RuntimeError，附带中文原因。

◆ update_firmware()

bool infrabot.update_firmware ( str  ip,
str  package,
str   public_key_file = '' 
)

[Blocking] 在触摸屏上确认后安装签名 IFW 固件包并返回 True；板子已经运行该包中的镜像时不发送任何数据，返回 False。

使用自己的维护套接字，不需要已连接的 Robot。请先托住机械臂、失能电机并断开电机电源。被拒绝、超时、固件包无效或校验失败时抛出 RuntimeError。
