infrabot.Mode类 参考

控制器的控制模式。 更多...

取值

Mode Idle = 0
 电机保持当前指令；不需要 PC 发流。
 
Mode RtJoint = 1
 PC 用 servej() 发送关节目标流。
 
Mode RtCartesian = 2
 PC 用 servep() 发送末端位姿流；控制器以 1 kHz 求解逆运动学。
 
Mode NrtJoint = 3
 用 movej() 做点到点关节运动。
 
Mode NrtCartesian = 4
 用 movep() 做末端直线运动。
 
Mode GravityFree = 5
 本地重力补偿：机械臂处于悬浮状态，可以用手拖动。
 
Mode GravityLock = 6
 本地重力补偿，并在当前位姿柔性保持。
 
Mode JointImpedance = 7
 以进入时的位姿为中心的本地关节阻抗。
 
Mode CartesianImpedance = 8
 以进入时的末端位姿为中心的本地笛卡尔阻抗。
 
Mode JointAdmittance = 9
 本地关节导纳；每个关节离限位至少要有 0.03 rad 余量。
 
Mode CartesianAdmittance = 10
 本地笛卡尔导纳；关节限位余量要求相同。
 
Mode Unknown = 255
 尚未知（收到第一包遥测之前）。

详细描述

控制器的控制模式。

导纳模式要求每个关节距离其限位至少 0.03 rad。
