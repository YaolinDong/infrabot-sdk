Detailed Description

Python API of the InfraBot SDK.

One Robot per arm controller. Joint values are in SI units: rad, rad/s, N·m. A call that fails raises RuntimeError with the reason, in Chinese.

◆ update_firmware()

bool infrabot.update_firmware ( str  ip,
str  package,
str   public_key_file = '' 
)

[Blocking] Installs a signed IFW package after approval on the touchscreen and returns True, or False without sending anything when the board already runs an image from the package.

Uses its own maintenance socket; needs no connected Robot. Support the arm, disable the drives and disconnect motor power first. Raises RuntimeError on refusal, timeout, an invalid package or a verification failure.
