[Blocking] Makes the board boot the other A/B slot.

Use it when a new firmware misbehaves: the board goes back to the image in its other slot. The board must run its normal application; approve the request on the touchscreen. The call returns once the other slot runs.

bool infrabot::update_firmware ( const std::string &  ipv4,

std::function< void(unsigned, unsigned)>  progress = {},

)

[Blocking] Installs a signed IFW package after approval on the touchscreen.

The board asks for approval on its touchscreen (60 s), writes the image into its inactive slot and boots it on trial. The call returns true once the new application confirms itself; a trial that fails returns the board to the previous firmware and the call throws. Completion requires a reply from the rebooted application with the expected image tag.

Parameters
ipv4Controller IPv4 address.
package_pathThe .ifw package.
public_key_filePublisher public key; empty selects the SDK's release key.
progressCalled with bytes sent and the total.
portMaintenance port.
Returns
false without sending anything when the board already runs an image from this package.
Exceptions
std::runtime_errorOn refusal, timeout, an invalid package or a verification failure.
